# Portfolio — Ayesha Lubna

Personal portfolio site showcasing my data science and ML projects.

**Stack:** React · TypeScript · Vite · Tailwind CSS · shadcn/ui

## Development

```bash
npm install
npm run dev      # local dev server with HMR
npm run build    # production build
```

## Featured projects

- [RAG Document Q&A](https://github.com/Ayshalubna/rag-document-qa) — production-ready retrieval-augmented generation system (LangChain, FAISS, FastAPI, Docker)
- [Sales AI Chatbot](https://github.com/Ayshalubna/neysa-sales-ai-chatbot) — natural-language analytics over sales data using an LLM
- [Skin Disorder Prediction](https://github.com/Ayshalubna/Skin-Disorder-Prediction) — 6-class clinical classification, 95%+ accuracy
